## Purpose

One-time onboarding that gathers what the user is learning and writes `.clinical-context.md` to the user's project root. All other skills check for this file and adapt accordingly.

## Step 1: Check for Existing Context

Scan the project root for `.clinical-context.md`.

- **If found:** Show the current preferences and ask: "Would you like to update your learning preferences, or are these still correct?"
  - If update → proceed to Step 2, pre-filling known answers
  - If correct → confirm and exit: "Your preferences are up to date. They'll be applied to everything I build."
- **If not found:** Proceed to Step 2.

## Step 2: Gather Learning Context

Ask these questions conversationally — never in a technical or survey-like tone. Adapt to the user's language (Spanish/English).

1. **Level:** "Where are you in your training?" (medical student / resident / practising clinician / other health professional / developer or curious learner)
2. **Specialty studied:** "Which specialty or topic are you studying?" (e.g., internal medicine, pediatrics, emergency medicine, cardiology)
3. **Case population:** "What kind of patients should the synthetic cases describe?" (adults / pediatric / geriatric / neonatal / mixed)
4. **Guidelines:** "Are there guidelines you want to learn against?" (e.g., Surviving Sepsis Campaign, ADA diabetes guidelines)
5. **Units:** "What units do you prefer?" (metric/imperial, mg/dL vs mmol/L for glucose, Fahrenheit vs Celsius for temperature)

**Rules:**
- Accept short answers — don't force elaboration
- If the user says "defaults are fine" for any question, use sensible defaults (practising clinician, internal medicine, adults, standard guidelines, metric + mg/dL + Celsius)
- Never ask technical questions about code, components, or architecture

## Step 3: Write Context File

Write `.clinical-context.md` to the project root with this format:

```
# Clinical Context

> Auto-generated by /medical-protocol:preferences. Re-run to update. For learning and prototyping, never patient care.

## Level
{answer}

## Specialty Studied
{answer}

## Case Population
{answer}

## Guidelines
{answer}

## Preferred Units
- Temperature: {Celsius/Fahrenheit}
- Glucose: {mg/dL or mmol/L}
- Weight/Height: {kg/cm or lbs/in}
- Blood pressure: mmHg (standard)
```

## Step 4: Confirm

Tell the user: "I've saved your learning preferences. I'll use them in everything I build and explain for you — units, guidelines, the synthetic cases, and how much detail I give. You can update them anytime with /medical-protocol:preferences."

## NEVER
- Ask technical questions (frameworks, databases, APIs)
- Require the user to answer every question — defaults are fine
- Overwrite an existing context file without asking first
- Store any patient-identifiable information in the context file (it holds the user's learning preferences, never patients)
